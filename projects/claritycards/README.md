# ClarityCards

A focused flashcard study app built with TypeScript and Vite. Move through a small deck, reveal answers, mark confidence, and review your session summary.

## Features

- Keyboard-friendly flashcard flow
- Reveal/hide answer state
- Confidence tracking (Again, Hard, Got it)
- Progress bar and session summary
- Resettable study session

## Run locally

```bash
npm install
npm run dev
```

Then open the local URL shown by Vite.

## Tech

TypeScript, Vite, HTML, CSS.
