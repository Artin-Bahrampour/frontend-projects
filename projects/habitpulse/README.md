# HabitPulse

A polished weekly habit tracker built with TypeScript and Vite. Track daily check-ins, see a live weekly score, and keep your habits stored locally in the browser.

## Run locally

```bash
npm install
npm run dev
```

## Features

- Add and remove personal habits
- Mark a habit complete for each day of the week
- Live completion score and progress indicator
- Reset the current week
- Local browser storage

## Tech

TypeScript, Vite, HTML, and CSS.
