# PocketPantry

A simple, polished grocery-list app built with HTML, CSS, and JavaScript. Add items, categorize them, estimate the remaining total, and keep the list stored locally in your browser.

## Run it

Open `index.html` in any modern browser. No installation is required.

## Features

- Add grocery items with a category and price
- Filter items by category
- Mark items as bought or remove them
- Live progress and remaining-total summary
- Local browser storage

## Tech

HTML, CSS, and JavaScript.
