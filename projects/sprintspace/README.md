# SprintSpace

A compact Kanban-style project board built with React and Vite. Add tasks, move them across the workflow, and keep the board saved in your browser.

## Run locally

```bash
npm install
npm run dev
```

## Features

- Create tasks with a project category
- Move tasks between To do, In progress, and Complete
- Live completion count
- Local browser storage

## Tech

React, Vite, JavaScript, HTML, and CSS.
