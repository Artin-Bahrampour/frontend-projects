# FocusFlow

A responsive, dependency-free task dashboard built with HTML, CSS, and JavaScript.

## Run it

Open `index.html` in any modern browser. No installation is required.

## Features

- Add, complete, and delete tasks
- Filtered progress at a glance
- Priority labels
- Browser local storage, so tasks survive a refresh

## Project structure

- `index.html` — page structure
- `styles.css` — responsive interface styling
- `app.js` — interactions and saved task state
